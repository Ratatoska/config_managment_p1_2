# Сравнение порядка с APT

Проверка сделана в Ubuntu 24.04, APT 2.8.3, на индексе Noble Main amd64.
Команда `apt-get -s` только моделирует установку. Программа на Python
APT не вызывает: индекс нужен ей напрямую для построения графа.

```bash
python src/main.py examples/hello.csv --load-order
apt-get -s --no-install-recommends install hello=2.10-3build1
```

| Проверка | Порядок |
| --- | --- |
| Python, граф из индекса | `gcc-14-base`, `libgcc-s1`, `libc6`, `hello` |
| APT, симуляция с пустым статусом | `gcc-14-base`, `libgcc-s1`, `libc6`, `hello` |
| APT, установленная базовая система | `hello` |

Чтобы проверить вариант без установленных пакетов, задайте APT пустой
файл статуса (источник Noble Main должен быть уже настроен):

```bash
status=$(mktemp)
apt-get -o "Dir::State::status=$status" -s --no-install-recommends \
  install hello=2.10-3build1
```

Python обнаруживает цикл `libc6 → libgcc-s1 → libc6`. Строгий порядок
графа для этого случая невозможен. Показанный порядок получается после
пропуска обратного ребра. APT решает задачу установки, учитывает уже
установленные версии и может распаковывать пакеты циклической группы,
а настраивать их после этого. Совпадение порядка для `hello` не означает,
что программа повторяет политику APT для всех пакетов.

На тестовом графе `diamond` получается `D, B, C, A`. На `cycle` есть
предупреждение о цикле, а `filtered` выводит только `B, A`.

## Сравнение графов на этапе 5

`apt-cache dotty` использован как штатный инструмент визуализации.
Рёбра `Depends` для трёх корней совпали с графом программы:

| Пакет | Прямые рёбра Python и APT |
| --- | --- |
| `hello` | `libc6` |
| `jq` | `libc6`, `libjq1` |
| `zlib1g` | `libc6` |

Транзитивно оба подхода показывают `libc6 → libgcc-s1` и обратное ребро,
а для `jq` также `libjq1 → libonig5`. Наш граф подписывает версии,
ограничивает глубину и показывает только обязательные зависимости.
У APT на диаграмме есть связи других типов: например, `hello` связан
с `hello-debhelper` из-за `Breaks`/`Replaces`. Поэтому полный вывод
`dotty` больше, хотя обязательные рёбра в проверенном подграфе совпали.
Команды для повторения сравнения: [compare_apt.sh](../scripts/compare_apt.sh).
